GeneralisedAutoCorrelation
==========================

Recurrence rate of a multichannel series as a function of the lag: how self-similar a movement is in time.

:bdg-primary:`Analysis primitives` :bdg-secondary:`timescale: any` :bdg-info:`EyesWeb: generalised\_auto\_correlation`
