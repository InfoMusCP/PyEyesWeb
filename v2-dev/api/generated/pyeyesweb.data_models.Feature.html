pyeyesweb.data_models.Feature#

class pyeyesweb.data_models.Feature[source]#

Base class of every feature: the call contract (process, run, reset) and the declared inputs and outputs.

A feature declares what one call receives (inputs) and what it returns (outputs) once, from its constructor parameters and before any data is seen. process takes one sample or frame per input and returns an immutable Result; run applies process to a whole recording and returns a Recorder.

A feature with several inputs (a pair of signals) takes them as positional arguments in the order of inputs: process(first, second, timestamp=None) and run(first, second, timestamps=None). timestamp and timestamps are keyword-only and in seconds.

Attributes:
inputsInputs

What one call receives (Inputs): kind, shape, labels.

outputsSchema

The declared outputs (Schema): names, shapes, component names, units.

latestResult or None

The last result with status OK, or None before the first one and after reset().

parametersmapping

The constructor parameters with their current values, as a read-only mapping.

Notes

Every call is first checked against inputs. A wrong shape raises ValueError naming the feature and the input; an empty frame is not a shape error and returns INVALID_INPUT, as do NaN or infinity and a timestamp that is not finite or goes back. The state is unchanged by an INVALID_INPUT call.

Every catalog feature is a subclass; custom features follow the same contract by declaring their inputs and outputs and implementing process.

Examples

A minimal custom feature, and the three ways of reading what it returns:

>>> import numpy as np
>>> from pyeyesweb.data_models import Feature, Input, InputKind, Inputs, Output, Schema
>>> class Speed(Feature):
...     _INPUTS = Inputs(Input("position", InputKind.SAMPLE, shape=(2,), unit="m"))
...     _OUTPUTS = Schema(Output("speed", unit="m/s"))
...     def __init__(self, sampling_rate=100.0):
...         self.sampling_rate, self._previous = sampling_rate, None
...     def process(self, position, *, timestamp=None):
...         position, previous, self._previous = np.asarray(position, float), self._previous, np.asarray(position, float)
...         if previous is None:
...             return self._no_output(timestamp=timestamp)
...         return self._result(speed=float(np.linalg.norm(position - previous)) * self.sampling_rate, timestamp=timestamp)
...     def reset(self):
...         self._previous = None
>>> feature = Speed()
>>> feature.outputs.flat_names, feature.latest
(('speed',), None)
>>> first = feature.process((0.0, 0.0), timestamp=0.0)
>>> first.status.name, first.valid["speed"]
('NO_OUTPUT', False)
>>> feature.process((0.03, 0.04), timestamp=0.01).speed
5.0
>>> recording = feature.run([[0, 0], [0.03, 0.04], [0.06, 0.08]], timestamps=[0.0, 0.01, 0.02])
>>> recording.speed.round(3).tolist(), recording.ok.tolist()
([nan, 5.0, 5.0], [False, True, True])

property inputs#

What one call receives (Inputs): kind, shape, labels. Known from the constructor parameters alone.

property latest#

The last result with status OK, or None before the first one and after reset().

Between two windows (NO_OUTPUT), during warm-up and on invalid input a call returns no new measurement and does not change this value; a caller that needs a continuous signal holds it: result if result.ok else feature.latest.

property parameters#

The constructor parameters with their current values, as a read-only mapping.

Like scikit-learn’s get_params. Change a parameter by assigning the attribute (feature.window = 50): the value is validated as in the constructor and applied live or restarts the state, according to the parameter (marked live or structural in the class documentation). A parameter the feature resolves at construction and does not keep (skeleton, which becomes labels, weights and pairs) is not listed.

run(*data, timestamps=None, reset=True)[source]#

Process a whole recording and return a Recorder with one row per sample (frame).

The numbers equal those of a loop of process().

Parameters:
*dataarray-like

One array per input, first axis = time (see inputs for the shape of one sample).

timestampsarray-like, optional

Timestamps in seconds, one per sample.

resetbool, optional

Start from a fresh state (default), or continue from the previous call.

Returns:
Recorder

One row per sample, including the rows that are not OK (see Recorder.status).

Raises:
ValueError

If the inputs do not have the same number of samples, timestamps does not hold one value per sample, or a sample does not fit inputs.
