Description#

class pyeyesweb.low_level.MotionNoiseDetector(labels=None, skeleton=None, *, noise_threshold=0.5, sampling_rate=None, units='m')[source]#

Noise test of the skeleton motion: whether the motion is random, with jumpy speeds.

For every watched joint the detector keeps the last 10 speeds and computes their variance; this variance is averaged over 5 frames and the motion is flagged as noisy (random, jumpy) when that mean exceeds noise_threshold. A still body, a uniform drift and the first frames have a small speed variance and are not flagged. The flag feeds the noise input of GestureSegmenter directly, which blocks the start of a gesture while it is set (True = judged to be noise): pass is_noisy together with the kinetic energy of the same frames, from KineticEnergy.

Two quirks of the original are kept: with several joints only the alphabetically last joint name that has a full window counts (a jumpy joint with any other name is not seen, whatever the order of labels; a single joint is judged on its own), and the flag is false until 14 speeds have been seen. This is the behaviour of the underlying EyesWeb block: only one joint decides.

Parameters:
labelssequence of str, optional

Joint names: the watched joints, which are also the names of the rows of an array frame (a dict frame carries its own). Taken from skeleton when that is given. (live)

skeletonstr or Skeleton, optional

A skeleton preset ("kinect_v2", …) or definition; its joints are the watched joints.

noise_thresholdfloat, optional

Threshold on the mean variance of the speed, a squared length: in m^2, scaled by units with the power 2. A threshold of 0 or less flags every frame as noisy, the first ones too. Defaults to 0.5. (live)

sampling_ratefloat, optional

Sampling rate of the frames in Hz, used when no timestamp is given. Defaults to None (one second per frame, and the reason says so). (live)

units{“m”, “mm”}, optional

Unit of the position data: scales noise_threshold (the data and the output are never scaled). Defaults to "m". (live)

Notes

Inputs. One skeleton frame per call: an (N, 3) array in the order of labels or a dict label -> (x, y, z). process(frame, *, timestamp=None); run(frames, *, timestamps=None) takes a (T, N, 3) recording. timestamp is in seconds, from which the time step is derived.

Outputs. is_noisy (bool): True when the motion is noisy, that is, random or jumpy: the mean speed variance exceeds noise_threshold. It is False for a still body, a uniform motion and the first 14 frames. It is valid on every call.

Statuses. OK on every valid call; INVALID_INPUT for a non-finite frame, an unknown joint or a timestamp that does not increase.

Corrected in the core: reset() left the per-joint speed windows in place; it now clears them.

Examples

>>> import numpy as np
>>> from pyeyesweb.low_level import MotionNoiseDetector
>>> rng = np.random.default_rng(0)
>>> frames = rng.normal(scale=0.3, size=(40, 1, 3))  # a joint that jumps about
>>> feature = MotionNoiseDetector(labels=["hand"], sampling_rate=50.0)
>>> still = feature.run(np.zeros((40, 1, 3))).is_noisy[-1]
>>> jumping = feature.run(frames).is_noisy[-1]
>>> bool(still), bool(jumping)
(False, True)
