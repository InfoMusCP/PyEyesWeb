Description#

class pyeyesweb.low_level.LogDimensionlessJerk(window=60, hop=1, *, sampling_rate=None, input_mode='velocity')[source]#

Log dimensionless jerk of a speed or acceleration profile: smoothness from the jerk of the movement.

The jerk, the rate of change of the acceleration, is large for a jerky movement and small for a smooth one. The log dimensionless jerk (LDLJ) normalises its squared integral by the duration and the peak amplitude of the movement, so that movements of different size and speed can be compared, and takes the negative logarithm. For a speed profile \(v(t)\) over a window of duration \(T\),

\[\mathrm{LDLJ} = -\ln\left( \frac{T^{3}}{v_{\max}^{2}} \int_{0}^{T} \left( \frac{d^{2}v}{dt^{2}} \right)^{2} dt \right),\]

with the derivatives taken by finite differences. In "acceleration" mode the input is the acceleration magnitude and the jerk is its first difference, normalised by the duration and the peak of the acceleration. The measure is dimensionless and negative; closer to 0 means smoother, and a flat signal gives 0.

Parameters:
windowint, optional

Samples per window (at least 10). Changing it on a running feature keeps the newest samples. Defaults to 60. (live)

hopint, optional

New samples between two windows. Defaults to 1. (live)

sampling_ratefloat

Sampling rate of the signal in Hz. Required: the window carries no time axis of its own. (live)

input_mode{“velocity”, “acceleration”}, optional

What the input holds: the speed (default) or the acceleration magnitude. LogDimensionlessJerk.from_velocity(...) and LogDimensionlessJerk.from_acceleration(...) build one or the other. (live)

Notes

Inputs. One value per call, process(value, *, timestamp=None): the speed (length/s) or the acceleration magnitude (length/s^2), used as given (no filtering); run(values, *, timestamps=None) takes a whole 1-D recording. Compute it beforehand, for example with Kinematics. timestamp only labels the result: it does not enter the computation and is not checked.

Outputs. log_dimensionless_jerk (dimensionless, negative; closer to 0 is smoother) of the last complete window.

Statuses. WARMING_UP while fewer than 10 samples are available ("k of N samples"), NO_OUTPUT between two windows when hop > 1, INVALID_INPUT when the profile cannot support the measure or a sample is NaN or infinite.

Differentiating a noisy signal amplifies the noise: filter or smooth the speed first.

Examples

>>> import numpy as np
>>> from pyeyesweb.low_level import LogDimensionlessJerk
>>> t = np.arange(100) / 100.0
>>> bell = np.sin(np.pi * t) ** 2  # one smooth bell-shaped speed peak
>>> feature = LogDimensionlessJerk(window=100, sampling_rate=100.0)
>>> round(float(feature.run(bell).log_dimensionless_jerk[-1]), 1)
-5.3
