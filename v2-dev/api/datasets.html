Datasets#

The example recordings used by the tutorials. The module needs no compiled core; downloading needs the optional dependency pooch (pip install pyeyesweb[datasets]). Reference for the objects below (generated from the docstrings).

load_qualisys_trial

Load one Qualisys recording of the example session.

QualisysTrial

One motion-capture trial.

fetch_data_file

Path of an example data file, downloading it first if it is not available locally.

available_trials

Numbers of the Qualisys trials that can be loaded now (local files, plus the registry once BASE_URL is set).

cache_dir

Directory where downloaded recordings are stored.

Data objects#

pyeyesweb.datasets.QUALISYS_TRIALS: dict[int, tuple[str, str]]#

Trial number -> (task, condition) of the recorded session.

pyeyesweb.datasets.BASE_URL: str | None#

URL of the folder that hosts the recordings; None until a host is chosen (the recordings are then read from a repository checkout or from the folder named by PYEYESWEB_DATA).

Where a file is looked for#

  1. the folder named by the environment variable PYEYESWEB_DATA, if set (it is also the download cache);

  2. examples/data of a repository checkout;

  3. the download cache, filled from BASE_URL with a SHA-256 check.

The recordings are Qualisys exports at 100 Hz with positions in millimetres; the loader keeps the millimetres and records them in the units field of the result.
