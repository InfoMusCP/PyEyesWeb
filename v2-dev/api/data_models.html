Data models#

Reference for the objects below (generated from the docstrings).

Feature

Base class of every feature: the call contract (process, run, reset) and the declared inputs and outputs.

WindowedFeature

A feature computed on a window of samples that it buffers itself.

Inputs

The inputs of a feature, in call order.

Input

One input of a feature.

InputKind

What one call to process receives for an input.

Schema

The ordered outputs of a feature, known before the feature is run and fixed for its life.

Output

Declaration of one output of a feature.

Result

What a feature returns: the values of its declared outputs for one call.

Status

Why a call produced (or did not produce) output.

Recorder

Records a stream of results as columns, one row per call.

Skeleton

The joints of a capture device and what the features need to know about them.

OutputsMixin

The output contract shared by every feature.
